DraftTap leverages high-performance, distributed architecture for real-time data processing, enabling scalable, fault-tolerant system and framework operations.

DraftTap is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/DraftTap.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure DraftTap, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
